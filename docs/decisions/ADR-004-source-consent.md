# ADR-004 — رضایت و مجوز منابع داده فاز اول

تاریخ: ۱۹ سپتامبر ۲۰۲۶

## زمینه

دو منبع فعال فاز اول `darukade` و `rosha` هستند. کرال عمومی کاتالوگ قیمت است، نه API خصوصی با کلید.

## تصمیم

- هر دو منبع به‌عنوان ویترین عمومی قیمت خوانده می‌شوند: User-Agent شفاف، rate-limit دامنه‌ای، احترام به `robots.txt`، ذخیرهٔ `raw` برای بازپردازش.
- کلید خصوصی یا حساب داروخانه در ریپو و پنل ذخیره نمی‌شود (کانفیگ منبع ماسک است).
- اگر منبع دسترسی را ببندد یا کتباً مخالفت کند، منبع در پنل disable می‌شود و کرال متوقف می‌گردد؛ دادهٔ خام برای ممیزی می‌ماند.
- انتساب نام داروخانه در جدول قیمت و گزارش کلیک حفظ می‌شود.
- افزودن منبع جدید بدون مرور همین رضایت/مجوز وارد برنامه نمی‌شود.

## پیامد

پوشش فاز اول به همین دو داروخانه محدود است تا رضایت روشن بماند. تصمیم پایلوت فاز دوم از گزارش کلیک واقعی (`/ops/dashboard` و `/ops/clicks`) گرفته می‌شود نه از حدس.
