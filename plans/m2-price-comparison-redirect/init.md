
## تصمیم‌های باز

- داروخانه‌ی دوم با API وصل شود یا کرال؟ اگر API نیازمند مکاتبه است، کرال را برای عبور از بلوکه‌شدن شروع کن.
- آستانه‌ی «قیمت کهنه» چند دقیقه/ساعت باشد؟ (این عدد بعداً در M5 هم استفاده می‌شود.)
- در صورت برابری قیمت دو داروخانه، ترتیب نمایش با چه معیاری باشد؟ (پیشنهاد: تازگی به‌روزرسانی، سپس نام.)
