# M4 — پنل تیم داده

**هدف:** حذف وابستگی عملیات به مهندس. تا وقتی افزودن داروخانه یا تطبیق کالا کار مهندس باشد، پلتفرم مقیاس نمی‌گیرد.

**نتیجه قابل اندازه‌گیری:** تیم داده یک داروخانه‌ی جدید را بدون کمک مهندس متصل می‌کند و کالاهایش را تطبیق می‌دهد.

**وابستگی:** M1 (خط داده) و M3 (جست‌وجو برای پیدا کردن کالا در صف تطبیق).

## آیتم‌ها

### [PH1-026] احراز هویت کاربران داخلی و نقش‌ها
**تخمین:** M — **نقش اجرا:** backend-dev + frontend-dev

- [x] ورود کاربر داخلی با نقش `data_ops` یا `super_admin`.
- [x] سشن با کوکی `HttpOnly` + `Secure` + `SameSite=Lax`؛ هیچ توکنی در `localStorage`.
- [x] middleware نقش روی همه‌ی مسیرهای `/api/v1/ops/...` اعمال می‌شود؛ کاربر بدون نقش `403` می‌گیرد.
- [x] محدودیت نرخ تلاش ورود به‌ازای کاربر و IP.
- [x] گروه مسیر `app/(admin)` در فرانت با چیدمان جدا و بدون ایندکس‌شدن توسط موتور جست‌وجو (`robots: noindex`).

## خارج از دامنه

داشبورد آمار مدیر (M7)، مدیریت کاربران داخلی توسط مدیر کل (M7)، پایش سلامت و صف بازبینی قیمت مشکوک (M5)، ورود OTP کاربران عادی (M6).

## ریسک

- **خطای اپراتور روی داده عمومی:** هر عملیات مخرب باید قابل بازگردانی و ثبت‌شده در audit باشد.
- **صف تطبیق پر شود و تیم عقب بماند:** تعداد `pending` یک KPI است؛ اگر رشد کند، آستانه‌ی تطبیق خودکار یا ظرفیت تیم باید بازبینی شود.
- **افشای کلید API منبع در پنل:** کلیدها فقط نوشتنی‌اند، خواندنی نه.
